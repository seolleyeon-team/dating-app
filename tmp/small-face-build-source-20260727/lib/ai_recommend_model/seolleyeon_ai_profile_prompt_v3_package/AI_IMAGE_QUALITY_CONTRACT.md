# Seolleyeon AI Image Quality Contract v3

## Target
Final approved set:
- 240 complete identities
- 720 approved images
- female identities: 120
- male identities: 120
- each identity has face_card, silhouette_card, vibe_card

## Hard reject
Reject immediately if:
- appears under 20
- school uniform
- teenager / childlike appearance
- idol trainee styling
- influencer photoshoot
- sexualized styling
- swimsuit / lingerie / revealing outfit
- nightclub / party / neon scene
- visible school logo
- readable university name
- readable brand/logo/watermark
- distorted face
- distorted hands/fingers
- unrealistic body proportions
- heavy beauty filter / plastic skin

## Shot requirements
face_card:
- adult face clearly visible
- natural smartphone profile photo
- head-and-shoulders or half-body
- not studio glamour

silhouette_card:
- 3/4 body or full body
- body frame and proportions readable
- no oversized padding
- no tight/revealing outfit
- camera not extreme wide-angle

vibe_card:
- same person as face_card
- calm campus/cafe/library/exhibition/walk mood
- face recognizable
- not nightlife
- not influencer content

## Identity consistency
For each identity:
- silhouette_card and vibe_card must look like the same person as face_card
- same core facial structure
- same approximate age
- same hair family unless metadata explicitly allows change
- same general body frame

## Distribution
The approved final set must satisfy:
- female identities: 120
- male identities: 120
- face_card assets: 240
- silhouette_card assets: 240
- vibe_card assets: 240
- looksLevel 4.4+ should be 0 or near 0
- no single faceType dominates the set
- no repeated background dominates the set
